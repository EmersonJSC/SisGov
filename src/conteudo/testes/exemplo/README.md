# Pacote de exemplo

Este pacote é artificial e existe para testar o fluxo de conteúdo. Não descreve um país real nem contém parâmetros empíricos.

Para adicionar conteúdo compatível, crie o arquivo JSON e inclua seu caminho no `cenario.json`. O carregador encontra todos os JSON distribuídos automaticamente; não é necessário registrar uma importação TypeScript para a nova política ou consequência.
