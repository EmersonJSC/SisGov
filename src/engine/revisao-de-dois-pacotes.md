# Revisão de dois pacotes

**Chamado:** SG024

**Estado:** implementado

Os pacotes artificiais `exemplo` e `alternativo` usam o mesmo carregador, validador, verificador de coerência e montador de grafo. Eles possuem IDs, políticas, controles, indicadores e unidades próprias.

Não há condição no motor pelo nome de nenhum país. Acrescentar um terceiro pacote segue o mesmo processo: arquivos JSON independentes e um manifesto.
